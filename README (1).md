# eScorer Bola Tampar — Liga Kumpulan

Pencatat skor bola tampar ringkas untuk liga kumpulan 4 pasukan (K.E.M, ADMINX, UNBEATEN, BUKAN BIASHE-BIASHE) dan 6 perlawanan.

**Buka:** https://hakim14-d.github.io/escorer-bola-tampar/

## Format
- Terbaik 3 set, setiap set 15 mata, mesti beza 2, deuce had 17
- Mata liga: menang 2–0 = 3 · menang 2–1 = 2 · kalah 1–2 = 1 · kalah 0–2 = 0
- 2 time-out (30 saat) setiap pasukan setiap set
- Gantian tanpa had: tekan pemain di gelanggang, masukkan nombor
- Animasi putaran pemain, tukar gelanggang pada 8 mata set ketiga
